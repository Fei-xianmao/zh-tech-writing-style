# 数字、单位与标点

对应原指南 §4.9～§4.11、§5、§7.2.3。本文的写作约定适用于解释文字；代码、参数原值、原始日志、URL 和逐字引文保留原样。项目标准有明确差异时，采用项目标准。

## 缩略语

依据：§4.9。

- 通俗且无歧义的中文简称可以使用；不常见的简称首次出现时说明全称与后文用法。
- 英文缩略语首次在正文出现时，建议解释完整含义，不在标题中堆放解释。例如“数据定义语言（Data Definition Language，DDL）”。
- 纯英文的括注用半角括号，如“数据定义语言 (DDL)”；括注含任何中文时用全角括号。
- 不使用不规范缩写，如以“16c32g”表示“16 核、32 GB”，以“10w”表示“10 万”。代码、实例规格标识或原始输入中出现这些字符时，保留原值，在说明文字中解释。

## 数字形式与书写

依据：§4.10。

- 计量、统计、编号和已经固定的名称通常用半角阿拉伯数字；禁止用全角数字代替，如“２５６”。
- 惯用汉语词、成语和概数保留汉字数字，如“一方面”“星期五”“三五天”。同一类别、同一层级的数字形式保持一致。
- 数字与中文解释文字之间通常留一个半角空格；数值本身不能断开换行。不要修改型号、序列号、地址、版本号内部的字符。
- 多位整数可用半角逗号每 3 位分节，如 `2,345,678`；小数部分不分节，4 位以内的整数可以不分节。编号和机器可读数值不加分节逗号。
- 大数可以用“万、亿”表达，但不能丢失精度或改变单位。中文概数中不用顿号分开相邻数字，如“三五天”，不用“三、五天”。
- 表示计量的 `0` 用“零”，逐位编号可用“〇”，如“二〇二五年”。常用量词前通常用“两”，序数、分数、小数中用“二”；强调统计时可直接用 `2`。

### 范围与日期时间

- 数值范围可用 `～` 或 `—`，如“64～1024 MB”；时间起止通常用 `—`，复合名称和完整数字日期用 `-`。
- 本技能默认将百分比范围写成“15%～30%”，保留两端符号以便辨认；原指南 §4.10.2 也允许在无歧义时省略前一个共同符号或单位。
- 年份用完整 4 位，如“2025 年”；年月日按自然顺序写。完整日期可用 `2025-01-06`，只有月份和日期时写“1 月 6 日”，不写容易混淆的 `1-6`。
- 时间统一选用 12 或 24 小时制，可写“14 时 12 分 36 秒”或 `14:12:36`；需要跨时区比较时保留已知时区，不自行补造。
- 特定事件名称按其惯用写法，如“‘3·15’消费者权益日”；不要给普通日期添加事件名称格式。
- 财务票据、法律文书的大写金额和数字格式服从对应业务要求，不用普通技术文档约定替换。

## 增加、降低与倍数

依据：§7.2.3。

| 表达 | 数学含义 | 例子 |
| --- | --- | --- |
| 增加了 2 倍 | 新值 = 原值 × 3 | 从 100 增至 300 |
| 增加到原来的 2 倍 | 新值 = 原值 × 2 | 从 100 增至 200 |
| 降低了 80% | 新值 = 原值 × 20% | 从 100 降至 20 |
| 降低到原来的 80% | 新值 = 原值 × 80% | 从 100 降至 80 |

- 不使用缺少“了／到”的“增加两倍”“降低 80%”来表达增减关系。
- 只知道“增加两倍”时无法判定最终值是 2 倍还是 3 倍，应向作者确认，不能自行改成其中一个结论。改写交付中可将该事实标为“待确认”，并保留原话供核对。
- 不使用“降低 N 倍”“减少 N 倍”。已知延迟从 100 ms 降至 20 ms，可写“降低了 80%”或“降至原来的 1/5”。
- 性能指标、比较基准、条件和测量口径应一致。原文只有“性能提升”时，不能自行改写成吞吐量或延迟的具体结论。

## 单位

依据：§4.11；原指南的摄氏度例外经过 PDF 页面核对。

| 情况 | 本指南默认写法 | 说明 |
| --- | --- | --- |
| 数字＋普通单位符号 | `7 kg`、`8 MB`、`100 ms` | 数值与单位间留一个半角空格 |
| 数字＋中文单位或量词 | `30 秒`、`16 核` | 中文与数字之间留空格 |
| 百分号、角度、摄氏度 | `80%`、`60°`、`37°C` | 按原指南 §4.11，不在数值与符号之间加空格 |
| 英尺、英寸 | `4′5″` | 不加空格，保留正确的 prime 符号 |

单位含义容易混淆时，可用“毫米、小时、分钟”等中文名称。`MB`、`Mb`、`MiB` 含义不同，不能为了统一外观互换；源材料单位不明时先确认。项目采用其他计量排版标准时，遵循其明确约定，不将本指南的 `37°C` 宣称为所有标准的唯一写法。

## 常用标点

依据：§5.1～§5.2。

| 标点 | 使用要点 |
| --- | --- |
| `。` | 完整陈述句用句号收束，分开不同的因果或操作，不“一逗到底” |
| `，` | 句内一般停顿，不替代所有句号 |
| `、` | 分开简短的并列词语，不分开完整分句；“以及、和、或”等连词前不再叠加顿号 |
| `；` | 区分较复杂的并列分句，尤其是分句内部已有逗号时 |
| `：` | 引出解释或列表，一个句子里避免多层冒号套用 |
| `“”`、`‘’` | 默认用弯引号，嵌套时外双内单；项目采用直角引号时统一，不混用 |
| `（）` | 含中文的补充说明；解释某词时紧跟该词，解释整句时放在句末标点后 |
| `《》` | 中文书刊名称；文档名称尽量写全，不自行缩写 |
| `—`、`-`、`～` | 分别常用于起止、复合名称和数值范围，注意与破折号区别 |
| `——` | 引出补充说明，占两个汉字位置，前后不额外加空格 |
| `……` | 中文省略号用 6 个点的形式，不以 3 个英文点代替中文省略号 |
| `！` | 少用，不连用多个感叹号 |
| `/` | 表示除法、单位比值或必要的“或”，两旁通常不加空格；多个并列对象优先用中文连接词 |

中文全角标点两旁不额外加空格。固定版面中避免句末标点、闭引号和闭括号出现在行首，也避免开引号、开括号和开书名号落在行末；交由支持中文排版的渲染器处理，不用随意插入空格修补。

## 中英文混排的例外

依据：§5.3。

- 中文句子以中文标点为主。嵌入的英文词组保留自身必需的英文标点，中文整句仍用中文句末标点。
- 引用完整英文句子时，用中文引号包裹，并保留引文内部原有标点；英文标题或引文结尾的问号、感叹号不能删掉。
- 括注全为英文时，建议使用半角括号：`预写日志 (write-ahead log)`。半角括号内部不加空格，括号外通常留一个空格；遇中文标点或行首行尾时不补多余空格。
- 括注含中文时，建议使用全角括号：`预写日志（write-ahead log，WAL）`，括号外不加空格。
- 英文书籍、报刊名用斜体；不能斜体时用中文引号，不用中文书名号。英文文章标题用中文引号。
- 原始报错、正则表达式、代码中的引号和括号不套用这些混排规则；文档只能在外层使用行内代码或代码块标示它们。
